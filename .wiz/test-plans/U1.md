# U1 — Premium UI polish + /switch role picker

## Acceptance criteria
- /switch route exists and renders 4 role cards (one per mock user from /v1/users).
- App boot redirects to /switch when localStorage has no role; otherwise renders dashboard.
- Picking a role persists `qnc.role` and navigates to `/`.
- The previous RoleSwitcher dropdown + its tests are deleted; no references remain.
- framer-motion installed; sidebar active-pill uses shared layoutId; route container has cross-fade.
- Reduced-motion media query disables animations.
- Empty states for Endpoints / Logs / Metrics with icon + one-line copy.
- Skeletons replace bare "loading…" text.
- Tokens layered (bg / bg-2 / panel / panel-elevated); cards have hairline border + top highlight + hover lift.
- JSON response panel in Playground is syntax-highlighted by a tiny inline tokenizer.
- All existing tests still green.

## Test scenarios
1. `<SwitchPage/>` renders 4 role cards (admin, developer, billing, viewer) when /v1/users mock returns 4 users.
2. Clicking a card persists `qnc.role` and navigates to `/`.
3. App with no localStorage role redirects to `/switch`.
4. RoleSwitcher.tsx + RoleSwitcher.test.tsx are deleted.
5. JSON syntax tokenizer produces tokens with class names for keys, strings, numbers, booleans, nulls.
6. EmptyState component renders an icon and message.
7. Skeleton component renders a div with `data-testid="skeleton"`.
8. Reduced-motion CSS rule exists in global.css.
