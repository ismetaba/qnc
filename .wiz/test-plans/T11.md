# T11 — root pnpm dev + smoke acceptance

## Acceptance criteria
- Root `package.json` script `dev` is `pnpm -r --parallel run dev`; every workspace has a `dev` script.
- Top-level README exists with run instructions + acceptance checklist.
- `pnpm smoke` (or equivalent) probes all 5 ports and reports up/down.
- `pnpm -r test` is green across all workspaces.

## Test scenarios
1. Static check: every workspace package.json has a `dev` script.
2. Smoke script: when given live ports, returns ok=true; when given a dead port, exit code != 0.
3. README contains the 5 spec acceptance bullets verbatim.
