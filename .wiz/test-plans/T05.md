# T05 — apps/api scaffolding + store + seed

## Acceptance criteria
- Fastify 5 server on port 4000 with CORS + pino-pretty.
- store.ts with `endpoints`, `rpcLog` (cap 2000), frozen `users` (4) + `invoices` (6).
- 3 seeded endpoints `eth-mainnet-prod`, `avax-cchain-prod`, `btc-mainnet-prod` with token `qnc_<nanoid20>`.
- Routes: `GET /health`, `GET /v1/users`, `GET /v1/endpoints`, `POST /v1/endpoints`, `DELETE /v1/endpoints/:id`, `GET /v1/billing/invoices`.

## Test scenarios (vitest, fastify.inject)
1. `GET /health` → `{ ok: true }`.
2. `GET /v1/users` returns 4 users with one of each role.
3. `GET /v1/endpoints` returns 3 seeded endpoints in expected names.
4. `POST /v1/endpoints` with valid body creates new endpoint with `qnc_` token.
5. `POST /v1/endpoints` with invalid chain returns 400.
6. `DELETE /v1/endpoints/:id` removes the endpoint.
7. `GET /v1/billing/invoices` returns 6 invoices.
8. `pushLog` slices to 2000 entries when overflowing.
