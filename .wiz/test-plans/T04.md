# T04 — BTC mock node

## Acceptance criteria
- `apps/node-btc` listens on 8503; chain `btc`, ticker `BTC`, tick 600 000 ms.
- `GET /` → `{ chain, ticker, blockHeight, uptimeS }`.
- `POST /` JSON-RPC dispatcher implementing all 12 BTC methods listed.
- Realistic shape: chain `'main'`, verificationprogress ~0.999, version `260000`, etc.
- Unknown method → error `-32601`.
- CORS headers everywhere.

## Test scenarios
1. `getblockcount` returns positive integer.
2. `getblockchaininfo` contains `chain`, `blocks`, `bestblockhash`.
3. `getnetworkinfo` returns object with `version === 260000`.
4. Unknown method → error code `-32601`.
5. CORS header `access-control-allow-origin: *` present.
6. `GET /` returns `chain === 'btc'`, `ticker === 'BTC'`.
