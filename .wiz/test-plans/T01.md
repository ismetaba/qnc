# T01 — Bootstrap pnpm monorepo

## Acceptance criteria
- Root `package.json` exists, is private, has `dev` script `pnpm -r --parallel run dev`.
- `pnpm-workspace.yaml` lists `apps/*` and `packages/*`.
- `tsconfig.base.json` is strict, ESM (`module: NodeNext`), `target: ES2022`.
- `.gitignore` covers `node_modules`, `dist`, build artefacts.
- `.npmrc` has `auto-install-peers=true`.
- `pnpm install` succeeds.
- `pnpm -r ls` succeeds (workspaces may be empty).

## Test scenarios (vitest, root)
1. `package.json` parsable; `private===true`; `scripts.dev` is `pnpm -r --parallel run dev`.
2. `pnpm-workspace.yaml` references both `apps/*` and `packages/*`.
3. `tsconfig.base.json` parsable; compilerOptions: `strict===true`, `module==='NodeNext'`, `target==='ES2022'`, `moduleResolution==='NodeNext'`.
4. `.gitignore` contains `node_modules` and `dist`.
5. `.npmrc` contains `auto-install-peers=true`.
