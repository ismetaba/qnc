# T07 — apps/web bootstrap + RoleContext + Sidebar

## Acceptance criteria
- Vite + React 18 + TS in apps/web on port 5180 strictPort.
- Vite proxies `/api` → `http://127.0.0.1:4000`.
- Plain CSS (no Tailwind).
- RoleContext hydrates from localStorage['qnc.role'], default `'admin'`; sets `data-role` on body.
- lib/api.ts typed wrappers for every API route.
- usePoll hook.
- Router with the 8 routes (placeholders fine for T07).
- Header with RoleSwitcher (lists 4 mock users), persists.
- Sidebar renders only ROLE_CAPS[role].nav.

## Test scenarios (vitest + RTL, jsdom)
1. RoleContext defaults to admin when localStorage empty.
2. RoleContext hydrates from localStorage when set to 'developer'.
3. Setting role updates localStorage + body data-role.
4. Sidebar renders all 8 nav items for admin.
5. Sidebar renders only `overview` + `billing` for billing role.
6. RoleSwitcher renders the 4 users when fetch is mocked.
7. Selecting a user from RoleSwitcher updates RoleContext + persists.
