# T08 — Overview + Nodes + Metrics pages

## Acceptance criteria
- Overview page: 4 stat cards, 3-card node fleet row, LiveLogTable, polls 4s.
- Nodes page: one large NodeCard per chain (block#, peers, latency, disk, uptime, sync%, version, progress bar), polls 2.5s.
- Metrics page: endpoint dropdown, window pills (1m/5m/1h/24h), 5 stat cards, BarChart of byMethod (plain SVG), polls 3s.
- Components: StatCard, NodeCard, BarChart, LiveLogTable, ProgressBar, ChainBadge.

## Test scenarios (vitest + RTL)
1. `<StatCard label value/>` renders label and value.
2. `<BarChart data/>` renders one `<rect>` per method.
3. `<ChainBadge chain/>` renders the canonical color via inline style or class.
4. `<ProgressBar value/>` clamps 0..1, renders fill.
5. `<NodeCard health/>` shows blockHeight + chain ticker.
6. `<LiveLogTable rows/>` renders all rows with method + duration.
