# T03 — EVM mock node (eth + avax)

## Acceptance criteria
- `apps/node-eth` listens on 8501 (chain `eth`, chainId `0x1`, tick 12 000 ms).
- `apps/node-avax` listens on 8502 (chain `avax`, chainId `0xa86a`, tick 2 000 ms).
- `GET /` returns `{ chain, ticker, blockHeight, uptimeS }`.
- `POST /` JSON-RPC dispatcher implements all 18 EVM methods (see spec).
- Unsupported method returns JSON-RPC error code `-32601`.
- CORS headers on every response.
- Tick increments blockHeight after the configured interval.

## Test scenarios (vitest, fastify.inject + fake timers)
1. `eth_blockNumber` returns hex string (`0x[0-9a-f]+`) and equals current state.
2. `eth_chainId` returns `0x1` for eth, `0xa86a` for avax.
3. Unknown method (`bogus_method`) returns error.code `-32601`.
4. `GET /` returns `{ chain, ticker, blockHeight, uptimeS }` with numeric fields.
5. After advancing fake timers past the tick window, blockHeight has increased.
6. Each handler dispatches `eth_getBalance`, `eth_gasPrice`, `eth_getBlockByNumber`, `eth_feeHistory`, etc. — pick a few to verify shape.
7. CORS headers (`access-control-allow-origin: *`) are present on responses.
