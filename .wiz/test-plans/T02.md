# T02 — packages/shared

## Acceptance criteria
- `@qnc/shared` package builds with `pnpm --filter @qnc/shared build`.
- Exports `Chain`, `Role`, `Endpoint`, `User`, `NodeHealth`, `RpcLogEntry`, `MetricSnapshot`, `UsageSummary`, `InvoiceLine`.
- Exports `ROLE_CAPS` covering all 4 roles, each with `nav` + 5 capability flags.
- Admin nav has all 8 items, billing has ≤2.

## Test scenarios (vitest, packages/shared)
1. ROLE_CAPS keys = `['admin','developer','billing','viewer']`.
2. Each role has `nav` array and the 5 boolean flags.
3. admin.nav.length === 8 and contains every item.
4. billing.nav.length <= 2.
5. developer cannot delete endpoint or manage users; viewer cannot create endpoint.
