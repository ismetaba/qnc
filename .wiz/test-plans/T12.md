# T12 — Sparkline + sidebar pulse

## Acceptance criteria
- `<Sparkline/>` renders an `<svg>` containing a `<polyline>` with N comma-separated point pairs.
- Per-endpoint sparkline strip on Overview page (last 30 durations per endpoint).
- Sidebar `nodes` nav gains a pulse dot driven by `/v1/nodes` poll (5s), green/amber/red.
- CSS `@keyframes pulse` animation; class `nav-dot--green|amber|red`.

## Test scenarios
1. `<Sparkline values={[…30 numbers]} />` → polyline.points has exactly 30 comma-separated pairs.
2. `<Sparkline values={[]}/>` renders the svg but no polyline (or empty).
3. `<Sparkline values={[5,5,5]}/>` (flat) renders without dividing by zero.
4. `<NodeFleetSparklines logs/>` groups by endpointId, one sparkline per endpoint with last 30.
5. `<Sidebar/>` with mocked /v1/nodes returning all healthy → nav-dot--green.
6. `<Sidebar/>` with mocked /v1/nodes containing one 'down' → nav-dot--red.
7. `<Sidebar/>` with mocked /v1/nodes containing one 'lagging' (no down) → nav-dot--amber.
